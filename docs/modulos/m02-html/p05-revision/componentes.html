Esta página reúne los elementos HTML que usa el sitio. De cada uno se muestra cómo se ve, su código y, cuando hace falta, una nota.

Texto

Encabezados

Los encabezados permiten organizar el contenido en diferentes niveles.

Encabezado de nivel 4

Encabezado de nivel 5
Encabezado de nivel 6
<h4>Encabezado de nivel 4</h4>
<h5>Encabezado de nivel 5</h5>
<h6>Encabezado de nivel 6</h6>

Párrafo <p> y salto de línea <br>

El párrafo organiza el texto, mientras que el salto de línea permite separar líneas cuando el contenido lo necesita.

Atendemos perros, gatos y animales pequeños.

Clínica Veterinaria ConSentidos
Santiago, Veraguas
Panamá 

<p>Atendemos perros, gatos y animales pequeños.</p>

<p>
    Clínica Veterinaria ConSentidos<br>
    Santiago, Veraguas<br>
    Panamá
</p>

Énfasis <strong>, <em> y <mark>

Cada uno comunica un significado distinto, no solo un aspecto visual.

La vacuna antirrábica es obligatoria cada año.

Tu mascota sí necesita agua fresca, aunque no la pida.

Recuerda traer el carné de vacunación a tu próxima cita.

<p>La vacuna antirrábica es <strong>obligatoria</strong> cada año.</p>

<p>Tu mascota <em>sí</em> necesita agua fresca, aunque no la pida.</p>

<p>Recuerda traer el <mark>carné de vacunación</mark> a tu próxima cita.</p>

Buena práctica: utiliza estas etiquetas por su significado, no solamente para cambiar la apariencia del texto.

Código <pre> y <code>

La etiqueta code identifica fragmentos de código, mientras que pre conserva los espacios y saltos de línea.

Para crear un párrafo se utiliza la etiqueta <p>.

<h1>Bienvenidos</h1>
<p>Esta es mi página web.</p>
<p>Para crear un párrafo se utiliza la etiqueta
<code>&lt;p&gt;</code>.</p>

<pre><code>&lt;h1&gt;Bienvenidos&lt;/h1&gt;
&lt;p&gt;Esta es mi página web.&lt;/p&gt;
</code></pre>

Fecha y hora <time>

La etiqueta time representa fechas y horas mediante un texto legible para las personas y un atributo datetime para las máquinas.

Nuestra próxima jornada de vacunación será el 5 de diciembre de 2026. 

<p>
    Nuestra próxima jornada de vacunación será el
    <time datetime="2026-12-05">5 de diciembre de 2026</time>.
</p>

Listas

Lista ordenada <ol>

La lista ordenada presenta elementos en una secuencia, generalmente mediante números o letras.

Pasos para atender una mascota:

  1. Registro en recepción.
  2. Triaje.
    1. Medición del peso.
    2. Medición de la temperatura.
  3. Consulta con el veterinario.
  4. Entrega de indicaciones.
<ol>
    <li>Registro en recepción.</li>
    <li>
        Triaje.
        <ol type="a">
            <li>Medición del peso.</li>
            <li>Medición de la temperatura.</li>
        </ol>
    </li>
    <li>Consulta con el veterinario.</li>
    <li>Entrega de indicaciones.</li>
</ol>

Lista no ordenada <ul>

La lista no ordenada presenta elementos cuyo orden no es importante. Generalmente utiliza viñetas.

Recomendaciones para el cuidado de una mascota:

  • Proporcionar agua fresca.
  • Mantener al día las vacunas.
  • Ofrecer una alimentación adecuada.
  • Realizar visitas periódicas al veterinario.
<ul>
    <li>Proporcionar agua fresca.</li>
    <li>Mantener al día las vacunas.</li>
    <li>Ofrecer una alimentación adecuada.</li>
    <li>Realizar visitas periódicas al veterinario.</li>
</ul>

Lista de descripción <dl>

La lista de descripción permite presentar términos acompañados de sus respectivas definiciones.

Desparasitación
Tratamiento que elimina parásitos internos o externos.
Microchip
Dispositivo que permite identificar a una mascota mediante un código.
<dl>
    <dt>Desparasitación</dt>
    <dd>Tratamiento que elimina parásitos internos o externos.</dd>

    <dt>Microchip</dt>
    <dd>Dispositivo que permite identificar a una mascota mediante un código.</dd>
</dl>

Enlaces

Enlace a otra página del sitio

Los enlaces internos permiten navegar entre las páginas de un mismo sitio web mediante rutas relativas.

Conoce nuestros servicios veterinarios. 

<a href="servicios.html">Conoce nuestros servicios veterinarios</a>

Enlace a un sitio de terceros

Los enlaces externos permiten visitar páginas de otros sitios web. Pueden abrirse en una pestaña nueva.

Consulta el sitio del Ministerio de Desarrollo Agropecuario (se abre en otra pestaña) . 

<a href="https://www.mida.gob.pa"
   target="_blank"
   rel="noopener noreferrer">
    Ministerio de Desarrollo Agropecuario (se abre en otra pestaña)
</a>

Buena práctica: utiliza rel="noopener noreferrer" junto con target="_blank" para mejorar la seguridad y privacidad al abrir otra pestaña.

Enlace de descarga

El atributo download permite ofrecer un archivo para descargar en lugar de abrirlo directamente.

Descargar la guía de vacunación (PDF) 

<a href="assets/docs/guia-vacunacion.pdf" download>
    Descargar la guía de vacunación (PDF)
</a>

Enlaces de correo y teléfono

Los enlaces mailto y tel permiten iniciar una acción de contacto desde el dispositivo del usuario.

Correo: citas@consentidos.example

Teléfono: +507 998-0000 

<a href="mailto:citas@consentidos.example">
    citas@consentidos.example
</a>

<a href="tel:+50799800000">
    +507 998-0000
</a>

Imágenes y multimedia

Imagen con leyenda <figure>

La etiqueta figure permite agrupar una imagen con una leyenda que describe o complementa su contenido. 

<figure>
    <img src="assets/img/luna.svg"
         alt="Ilustración de Luna, una gata gris atigrada, sentada"
         width="320" height="240" loading="lazy">
    <figcaption>Luna, paciente del mes.</figcaption>
</figure>

Audio <audio>

La etiqueta audio permite insertar archivos de sonido en una página web y ofrecer controles para reproducirlos.

Tono de recordatorio de citas:

<p id="etq-audio">Tono de recordatorio de citas:</p>

<audio controls preload="metadata" aria-labelledby="etq-audio">
    <source src="assets/media/recordatorio.mp3" type="audio/mpeg">
    Tu navegador no reproduce audio.
    <a href="assets/media/recordatorio.mp3">Descarga el tono</a>.
</audio>

Video con subtítulos <video>

La etiqueta video permite reproducir videos en una página web. También admite subtítulos para facilitar su comprensión. 

<video controls width="640" height="360" preload="metadata"
       poster="assets/media/consejos-poster.jpg">
    <source src="assets/media/consejos.webm" type="video/webm">
    <source src="assets/media/consejos.mp4" type="video/mp4">
    <track kind="subtitles" src="assets/media/consejos-es.vtt"
           srclang="es" label="Español" default>
    Tu navegador no reproduce video.
    <a href="assets/media/consejos.mp4">Descarga el video</a>.
</video>

Página incrustada <iframe>

La etiqueta iframe permite mostrar otra página web dentro de la página actual. 

<iframe src="paginas/test.html"
        title="Página de prueba del sitio de ConSentidos"
        width="600" height="240" loading="lazy">
</iframe>

Mapa incrustado de terceros

También podemos incorporar contenido de otros sitios web, como mapas interactivos. 

<iframe
    src="https://www.openstreetmap.org/export/embed.html?bbox=-80.9950%2C8.0900%2C-80.9650%2C8.1100&layer=mapnik"
    title="Mapa de Santiago de Veraguas, donde está la clínica"
    width="600" height="340" loading="lazy"
    referrerpolicy="no-referrer"
    sandbox="allow-scripts allow-popups">
</iframe>

Documento PDF incrustado <object>

La etiqueta object permite mostrar documentos externos, como archivos PDF, dentro de una página web. 

<object data="assets/docs/guia-vacunacion.pdf"
        type="application/pdf" width="600" height="400"
        aria-label="Guía de vacunación de ConSentidos, en PDF">
    <p>Tu navegador no muestra PDF.
        <a href="assets/docs/guia-vacunacion.pdf">
            Descarga la guía
        </a>.
    </p>
</object>

Elementos interactivos

Preguntas frecuentes <details>

Las etiquetas details y summary permiten crear preguntas desplegables sin utilizar JavaScript.

¿Cada cuánto debo desparasitar a mi perro?

Cada tres meses, con la dosis que indique el veterinario.

¿Necesito cita para vacunar?

Sí. Así preparamos la vacuna y revisamos antes su carné.

<details name="preguntas">
    <summary>¿Cada cuánto debo desparasitar a mi perro?</summary>
    <p>Cada tres meses, con la dosis que indique el veterinario.</p>
</details>

<details name="preguntas">
    <summary>¿Necesito cita para vacunar?</summary>
    <p>Sí. Así preparamos la vacuna y revisamos antes su carné.</p>
</details>

Medidor y barra de progreso <meter> y <progress>

El elemento meter representa una medida dentro de un rango, mientras que progress muestra el avance de una tarea.

4,2 kg 4,2 kg (rango saludable: 3 a 5 kg)

2 de 5 dosis 2 de 5 dosis 

<p>
    <label for="peso-luna">Peso de Luna</label>
    <meter id="peso-luna" min="0" max="8" low="3" high="5"
           optimum="4" value="4.2">4,2 kg</meter>
    4,2 kg (rango saludable: 3 a 5 kg)
</p>

<p>
    <label for="plan-vacunas">Plan de vacunación de Max</label>
    <progress id="plan-vacunas" value="2" max="5">2 de 5 dosis</progress>
    <output id="plan-texto" for="plan-vacunas">2 de 5 dosis</output>
</p>
