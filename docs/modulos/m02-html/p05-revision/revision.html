Política de seguridad de contenidos

La política de seguridad se construyó utilizando default-src 'self' como regla general y agregando directivas específicas para controlar los recursos permitidos. Se autorizaron únicamente los orígenes necesarios para los estilos, fuentes y el mapa externo de OpenStreetMap.

Directivas de la política y por qué están
Directiva Valor Por qué
default-src 'self' Regla por defecto: solo recursos del propio sitio.
script-src 'self' Permite ejecutar scripts únicamente del propio sitio.
style-src 'self' https://fonts.googleapis.com Permite hojas de estilo locales y estilos de Google Fonts.
font-src https://fonts.gstatic.com Permite cargar las fuentes de Google Fonts.
img-src 'self' Permite imágenes alojadas en el propio sitio.
media-src 'self' Permite archivos multimedia del propio sitio.
object-src 'self' Permite documentos incrustados, como el PDF local.
frame-src 'self' https://www.openstreetmap.org Permite marcos del propio sitio y el mapa de OpenStreetMap.
base-uri 'self' Restringe la dirección base de las rutas al propio sitio.
form-action 'self' Permite enviar formularios únicamente al propio sitio.

La directiva frame-ancestors no está activa en este sitio porque solo puede configurarse mediante una cabecera HTTP y no mediante una etiqueta meta. GitHub Pages no permite configurar directamente estas cabeceras HTTP, por lo que no es posible aplicar esta protección desde el alojamiento utilizado.

La validación del navegador no protege

Al principio, el navegador impidió enviar el formulario porque algunos campos obligatorios estaban vacíos. Después, mediante las herramientas de desarrollador, eliminé temporalmente el atributo required del campo de correo electrónico y modifiqué el valor del campo oculto. Esto permitió comprobar que las validaciones del lado del cliente pueden modificarse o evitarse. Por esta razón, el servidor también debe validar los datos recibidos para garantizar la seguridad y confiabilidad de la información.
